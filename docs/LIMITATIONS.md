# 限制

- **相關模型偏誤**：不同上下文可能使用同一模型、訓練資料與提示，十二票不是十二個統計獨立觀測。共用假設可能一起錯誤。
- **角色模擬**：專業描述不等於專家資格；法律、科學與金融結論有不確定性，重要事項仍需合格人士與原始證據確認。
- **共識與真實性**：多數只能整理模型立場，不可當作客觀正確性或成功機率。少數與高影響低可能性風險仍保留。
- **提示敏感性**：提案措辭、背景、角色、順序與原始錯誤資料會影響結論。提案中的指令視為資料，但文字指示不能形成強安全邊界。
- **外部證據**：V1 無自動研究。為維持任務可見性，陪審與辯論代理禁止工具及讀檔，因此拒收 `verified`。引用網址本身不證明內容正確，使用者提供資料仍標記為未獨立驗證。
- **可重現性**：Mock 可確定性重播；真實 LLM 可能因模型版本、抽樣與服務變更而不同。模型與用量無法取得時為 `null`／「無法取得」。封存設定不是服務端可重現性的保證。
- **執行依賴**：原生流程須有可建立新上下文的 Codex 客戶端；本次只實測一個探測代理及續接，尚未執行真實十二人全流程。TOML 不會自行啟動代理，也未在本工作階段驗證自動載入。
- **共享檔案系統**：子代理可繼承工具與權限。傳遞純任務包並禁止工具能限制預期資料流，但不提供 OS 級資料隔離。若代理違反邊界，該輪不應當作有效獨立評估。
- **來源聲明**：`native_attested` 與 `operator_attested` 都是操作者聲明；程式驗證 ID、階段與結構，無法認證代理是否真的執行。測試的合成 context ID 不代表 LLM 執行證據。
- **分析範圍**：分歧假設以個別投票列出，直接矛盾則抽取陪審員明確引用的兩個來源，不執行額外語意裁判。少數報告是抽取原始疑慮與推翻條件，不補造「少數已證明正確」的研究結論。
- **平台**：檔案鎖採 POSIX `flock`，目前支援 macOS／Linux；Windows 原生鎖尚未實作。不是多主機分散式執行器。
- **歷史保存**：結果存本機 UTF-8 檔案，可自行審查後提交 GitHub。未實作自動提交每次評估、加密、權限系統或雲端備份。對有本機寫入權限的人不提供防竄改保證。
- **未實作項目**：付費 API、自動 `codex exec` 批次執行、跨模型比較、進階實驗分析。未配置 API 憑證，也不默默用單一角色扮演補缺件。

# V1.0 驗收標準與證據邊界

| 項目 | 驗證方法 | 通過條件 |
| --- | --- | --- |
| 專案結構與設定 | validate.py + check_codex.py | 10 份 TOML、官方欄位、原生 strict parser 接受；未知鍵負向控制拒絕 |
| 自然語言觸發 | AGENTS.md 檢查 + 新對話 T01–T04 | 無需 slash command；真實派發後完整報告；文件檢查不能替代新會話測試 |
| 真正委派與回收 | 原生 Smoke Test 工具紀錄 | 原生 agent IDs、不同 context、實際 JSON 回傳；不得偽造 |
| 正確角色 | Schema agent_id/role/specialty 約束 + 工具輸入 | 各人正確身份與 A08 固定專業，沒有偷偷換角色 |
| 獨立盲審 | 派發、檔案與傳訊工具紀錄人工核對 | 停用歷史、同一封包、沒有 peer 結果或互傳；不宣稱強制隔離 |
| 結構與語意 | Draft 2020-12 + council_checks.py | 單方案與比較票正確；方案完整、排名無重複、證據參照有效 |
| 統計與鎖票 | 契約測試 | 缺席不算票、重試不重複計票、並列口徑明確、鎖定快照不變 |
| 條件式驗證 | 契約測試 + 重大風險原生 Smoke Test | 重大風險觸發；純價值分歧可跳過；最多兩種驗證角色，不重投 |
| 失敗恢復 | 契約測試 + T10 人工故障注入 | 最多重試一次、保留有效票、揭露缺席；合成測試不能證明原生 timeout 恢復 |
| 報告完整 | 九節模板 + Smoke Test 報告人工核對 | 繁體中文、保留少數意見、引用真實、未解與未啟動分開 |
| 權限 | 根設定與工具紀錄 | 評估唯讀、維護需明確寫入能力，無高權限繞過 |
| 無原生能力 | T12 | Council 未執行／0 票／INSUFFICIENT_EVIDENCE，沒有主代理扮演評審 |

初始化完成表示必要檔案及可行驗證已交付、限制已揭露；不表示所有宿主、
版本、外部來源與失敗分支均已完成動態認證。具體結果見 `results/validation.md`。
